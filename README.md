# projects-tailwind-game-landing

[![Hexlet Ltd. logo](https://raw.githubusercontent.com/Hexlet/assets/master/images/hexlet_logo128.png)](https://hexlet.io?utm_source=github&utm_medium=link&utm_campaign=projects-tailwind-game-landing)

Ассеты проекта «Лендинг игры» на Хекслете: лендинг пародийной игры Kubercraft, свёрстанный на Tailwind CSS без JavaScript.

- [images](images) — пиксельная графика: спрайты предметов 16×16, фоновые блоки и скриншоты игры.
- [fonts](fonts) — шрифты Pixel Code (текст) и Pixeloid Sans (заголовки), оба под OFL 1.1, лицензии лежат рядом.
- [content.md](content.md) — все тексты страницы по секциям и какая картинка где стоит.
- [test-images](test-images) — эталонные снимки, с которыми проверка сравнивает страницу. Имя файла собрано из ширины (`desktop` 1440 px, `mobile` 414 px), темы (`overworld` или `nether`), секции и состояния.

This repository is created and maintained by the team and the community of Hexlet, an educational project. [Read more about Hexlet](https://hexlet.io?utm_source=github&utm_medium=link&utm_campaign=projects-tailwind-game-landing).
